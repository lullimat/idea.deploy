# The full research-workstation stack, installed by idpy-init.sh.
#
# NOT idpy's own dependencies. Those live in pyproject.toml and are what
# `pip install idpy` resolves; this file adds everything a working environment
# wants on top -- Jupyter, opencv, plotly, kaleido, python-sat and friends.
# idpy-init.sh installs both: this file, then `pip install -e .`.
#
# Some packages are named in both places today. That is duplication rather
# than disagreement, and consolidating it means changing what gets installed,
# so it is left alone here on purpose.

# appdirs and pybind11==2.9.2 used to be here, and both belonged to building
# pycuda and pyopencl from source. Neither is built here any more -- both come
# as wheels -- and under PEP 517 build isolation a build would take its
# requirements from the package's own metadata rather than from this file, so
# the pin could never have helped and could only have constrained the
# environment. appdirs was superseded by platformdirs, which pytools installs.
